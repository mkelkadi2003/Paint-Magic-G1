🔵 Mission 1: The Shape Spell

Draw circles and ovals, then move them around!

Steps: Open MS Paint → Shapes → Oval → Click & drag → Release. To move: select and drag.
Draw 3 circles and move them to different places!

🔍 Mission 2: The Resizing Magic

Select a shape and drag its handles to resize!

Steps: Select shape → Find corner handles → Drag to make bigger/smaller → Stretch into an oval.
Can you turn the small circle into a BIG oval?

✨ Mission 3: The Clone Spell

Create two identical balloons, then make them different colors!

Steps: Draw shape → Select → Copy → Paste → Move duplicate → Change colors → Draw strings.
Draw one balloon, copy it, and make two colorful balloons!

🧹 Mission 4: The Cleanup Magic

Delete unwanted shapes and compare line widths!

DELETE: Select shape → Delete. LINE WIDTH: Select shape tool → Size → choose width.
Line width:
Challenge 1: Delete the unwanted shape! Challenge 2: Choose the thickest line!
